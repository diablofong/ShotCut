# 操作說明

## 流程總覽

ShotCut 的操作流程分為四步：

```
上傳影片 → 標記時間點 → 擷取片段 → 分享
```

---

## 第一步：上傳影片

有兩種方式新增影片：

=== "上傳本機檔案"
    1. 前往**影片**頁面
    2. 點擊**上傳影片**
    3. 選擇 `.mp4` 檔案（預設最大 2GB）
    4. 等待上傳完成

=== "從 YouTube 匯入"
    1. 前往**影片**頁面
    2. 點擊**從 YouTube 匯入**
    3. 貼上 YouTube 網址
    4. 即時進度條顯示下載速度與剩餘時間

---

## 第二步：標記時間點

1. 點擊影片進入播放器
2. 播放影片，使用鍵盤快捷鍵標記關鍵時刻：

| 按鍵 | 動作 |
|------|------|
| `1` | 進攻 |
| `2` | 防守 |
| `3` | 失誤 |

3. 每個標記自動捕捉按鍵前後各 5 秒的片段
4. **拖曳時間軸色塊**可微調開始/結束時間點
5. **新增球員標註** — 點擊標記後輸入球員編號與姓名（如 `7 林書豪, 11 王大明`）
6. 播放速度調整：`0.25x` – `2x`，支援慢動作回放

---

## 第三步：擷取片段

標記完成後：

1. 選擇要擷取的標記（或全選）
2. 點擊**擷取片段**
3. FFmpeg 在背景處理片段
4. 完成後片段出現在**片段**清單

### 產生精華剪輯

將多個片段合併為一支精華影片：

1. 前往**精華剪輯**頁面
2. 選擇篩選條件：依**球員**或依**分類**（進攻/防守/失誤）
3. 點擊**產生精華**
4. 完成後下載合併影片

---

## 第四步：分享

1. 開啟片段或精華剪輯
2. 點擊**建立分享連結**
3. 選擇有效期限：**24 小時 / 7 天 / 30 天 / 永久**
4. 複製連結傳給教練或家長

!!! info
    收到連結的人**不需要登入**即可觀看，無需帳號。

---

## 使用技巧

- 使用 **0.25x 慢動作**逐格檢視爭議球判定
- 使用 **2x 快速瀏覽**快速掃過長時間比賽影片
- 球員標註會出現在匯出檔名中，方便依球員整理精華
- 分享連結到期後自動失效，無需手動管理
